# Machine Learning Labs

Lab works from my university course "Machine Learning Methods".
All work is done in Python (pandas, NumPy, scikit-learn, matplotlib, seaborn).

| Lab | Topic |
|-----|-------|
| [Lab 1](lab1_eda) | Exploratory data analysis and data preparation |
| [Lab 2](lab2_linear_regression) | Linear regression: gradient descent from scratch, L2 regularization |
| [Lab 3](lab3_classification) | Binary classification: Logistic Regression, SVM, Decision Tree |
| [Lab 4](lab4_gradient_boosting) | Gradient boosting and hyperparameter tuning |

## How to run
1. Install the libraries: `pip install -r requirements.txt`
2. Open any notebook in Jupyter and run all cells.
