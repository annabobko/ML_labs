# Lab 1: Exploratory Data Analysis (EDA)

## Goal
Explore a real dataset and prepare it for machine learning.

## Data
Kaggle [dataset](https://www.kaggle.com/datasets/mahdimashayekhi/social-media-vs-productivity) about the impact of social media on productivity.

## What I did
- Checked the data: types, distributions, basic statistics
- Handled missing values and outliers
- Encoded categorical variables
- Looked at relationships between features
- Created new features
- Scaled the data

## Tools
Python, pandas, NumPy, matplotlib, seaborn
