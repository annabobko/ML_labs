# Lab 4: Binary Classification

## Goal
Compare several classification algorithms on one task.

## Models
- Logistic Regression
- Support Vector Machine (SVM)
- Decision Tree (CART)

## What I did
- Trained all three models on the same [data](https://www.kaggle.com/datasets/prekshad2166/healthy-meal-plan-dataset)
- Compared them using precision, recall and F1-score
- Built confusion matrices and ROC curves, calculated ROC-AUC

## Tools
Python, pandas, scikit-learn, matplotlib, seaborn
